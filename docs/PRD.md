# [PRD] FITMATE — 친구들과 작심삼일을 운동 습관으로 바꾸는 AI 소셜 홈트레이닝

> GitHub 이슈로 발행할 원본. 내용을 바꾸면 이 파일과 이슈를 함께 고친다.
> 원본: PM 매니패스트 문서(유저플로우 v5, 2026-11-06 기준으로 갱신). 2026 멋쟁이사자처럼 1호선톤 출품용 데스크톱 웹 MVP.

## 문제 정의 (Problem Statement)

운동의 필요성은 느끼지만 혼자서는 동기가 부족해 작심삼일로 끝나는 홈트레이닝 관심층이 있다. 헬스장과 필라테스는 시간과 비용이 부담스럽다. 유튜브나 기존 홈트 앱을 써도 자신의 목표와 능력에 맞는 루틴을 찾기 어렵고, 동작을 제대로 하고 있는지 확인하기 어렵고, 함께하는 재미가 없어 영상을 끄면 그만이다.

## 해결책 (Solution)

사용자는 랜딩에서 시작해 회원가입 없이 닉네임과 캐릭터로 임시 프로필을 만든다. 홈에서 '친구들과 운동하기'를 고르면 체중 감량, 자세 개선, 근력 강화, 체력 증진 중 목표 하나를 고르고, 운동 2~3개로 된 `루틴`을 추천받은 뒤 미리 지정된 `운동방`에 입장한다.

`운동방`은 실제 3D 공간이다. `참가자`는 서로 다른 PC에서 접속해 각자 다른 운동을 원하는 시점에 시작하고 끝낸다. 별도의 `AI 가이드`가 올바른 동작을 시범 보이고, 웹캠으로 인식한 실제 움직임이 내 캐릭터와 친구 화면의 캐릭터에 반영된다. 기준을 충족한 동작만 `유효 횟수`로 세고, 미달하면 짧은 자세 피드백을 준다. 친구 캐릭터를 클릭하면 `응원`을 보낼 수 있다.

운동이 끝나면 자신의 `수행 기록`과 그로 인한 `팀 경험치` 변화를 보고, 1회차 결과에 근거한 2회차 `루틴`과 변경 이유를 확인한다. 홈이나 결과 화면에서 `성장 기록`으로 회차별 기록과 변화를 다시 볼 수 있다. 측정하지 못한 것은 기록하지 않으며, 근거가 부족하면 난도를 올리지 않는다.

부가 콘텐츠(P1)로, 홈의 보조 카드에서 밤 10시쯤 열리는 `공개 선셋 파티`에 들어가 친구가 아닌 참가자들과 같은 야외 3D 공간에서 각자 에어로빅을 할 수 있다. 친구 파티의 2~5인 제한은 적용하지 않으며, 이 기능을 위해 P0 친구 파티 범위를 줄이지 않는다.

## 사용자 스토리 (User Stories)

1. As a 홈트 입문자, I want 목표만 고르면 오늘 할 운동과 수행량을 추천받고 싶다, so that 어떤 운동을 할지 찾느라 시작을 미루지 않는다.
2. As a 친구와 운동하려는 사용자, I want 가입이나 초대 없이 닉네임과 캐릭터만 정해 운동방에 들어가고 싶다, so that 짧은 준비로 바로 함께 시작할 수 있다.
3. As a 자세가 걱정되는 사용자, I want AI 가이드를 따라 하면서 유효 횟수와 자세 피드백을 받고 싶다, so that 혼자서도 동작을 제대로 하고 있는지 알 수 있다.
4. As a 참가자, I want 내 실제 움직임이 캐릭터에 반영되고 친구의 움직임과 운동 현황도 보고 싶다, so that 집에 있어도 같은 공간에서 함께 운동하는 느낌을 받는다.
5. As a 친구와 일정이 다른 참가자, I want 각자 다른 운동을 원하는 시점에 시작하고 끝내고 싶다, so that 친구가 쉬거나 끊겨도 내 운동이 멈추지 않는다.
6. As a 참가자, I want 친구 캐릭터를 클릭해 응원을 주고받고 싶다, so that 힘들 때 운동을 이어갈 동기를 얻는다.
7. As a 1회차를 마친 사용자, I want 실제 결과와 그에 근거한 2회차 루틴·변경 이유를 보고 싶다, so that 내 수준에 맞게 운동이 발전한다는 것을 이해한다.
8. As a 팀원, I want 내 운동이 팀 경험치로 쌓이는 것을 보고 싶다, so that 친구들과의 공동 성장을 보며 다시 참여하게 된다.
9. As a 몇 회차를 이어 온 사용자, I want 내 회차별 기록과 누적량, 추천이 어떻게 바뀌었는지 다시 보고 싶다, so that 내가 실제로 나아지고 있는지 확인하고 다음 운동을 이어간다.
10. As a 함께 운동할 친구가 없는 사용자, I want 정해진 시간에 열리는 공개 운동장에서 다른 사람들과 각자 운동하고 싶다, so that 혼자라도 함께하는 분위기에서 운동을 시작한다. _(P1)_

## 구현 결정 (Implementation Decisions)

### 플랫폼과 배포

- 데스크톱 웹 전용이다. 서로 다른 PC 2~5대의 동시 접속을 검증한다.
- PM 문서가 PoC 수치를 제품 성능으로 쓰지 말라고 정했고, 개발팀이 카메라 인식·3D 움직임·다중 연결을 별도 데모로 사전 검토했다. 그 결과 자료는 이 PRD의 근거로 확인하지 못했다.
- 프론트엔드, 백엔드, DB, 동작 인식 모델, 3D 렌더링, 실시간 통신, 배포처는 **미정**이다. 착수 전에 개발팀이 정하고 ADR로 남긴다.

### 모듈과 경계

1. **루틴 추천**: 목표와 이전 수행 기록을 받아 회차별 루틴과 변경 이유를 만든다.
2. **참가자 식별**: 임시 식별값, 닉네임, 캐릭터를 관리하고 기록과 연결한다.
3. **운동방 실시간 공유**: 참가자의 입퇴장, 진행 상태, 연결 상태, 동작 정보, 응원을 같은 방에 전달한다.
4. **동작 인식과 판정**: 카메라 영상에서 동작 정보를 얻어 유효 횟수와 자세 피드백을 낸다.
5. **3D 운동 공간**: 공간, 참가자 캐릭터, AI 가이드를 그리고 동작 정보를 캐릭터에 반영한다.
6. **운동 진행**: 개인 운동 상태를 전환하고 수행 기록을 확정한다.
7. **결과와 팀 성장**: 확정된 기록으로 결과를 보여주고 팀 경험치를 적립한다.
8. **성장 기록**: 본인의 확정된 기록과 추천 이력만 모아 회차별 변화와 누적량을 보여준다.
9. **공개 파티 (P1)**: 설정된 오픈·종료 시각에 따라 공개 운동장을 열고, 정원 제한 없이 운동방 실시간 공유를 재사용한다.

3D 운동 공간은 판정 규칙을 몰라도 되고, 동작 인식은 친구나 운동방을 몰라도 된다. 운동방 실시간 공유는 내용을 해석하지 않고 전달만 하며, 다른 참가자의 상태가 개인 운동 진행을 바꾸는 경로를 만들지 않는다. 팀 경험치와 2회차 추천은 확정된 수행 기록만 입력으로 받는다.

### 데이터 공급자와 역할

현재 PM 문서에 정해진 외부 API는 없다. 추천을 규칙으로 만들지 외부 AI 모델을 쓸지 정해지면 용도, 비용도, 공식 문서 링크를 이 섹션에 추가한다.

**결측·실패 처리 규칙:** 측정하지 못한 값은 `0`이나 추정값으로 채우지 않고 미측정 상태로 둔다. 판정 불가는 미카운트 또는 판정 보류로 처리한다. 연결이 끊긴 친구는 마지막 상태를 현재처럼 표시하지 않고 연결 불안정으로 표시한다. 기록이나 경험치가 확정되지 않으면 성공값을 표시하지 않는다.

### 운동 판정과 기록의 정직성

- 기준 미달과 판정 불가 동작은 유효 횟수에 넣지 않는다.
- 자동 애니메이션과 AI 가이드의 시범은 실제 수행으로 기록하지 않는다.
- 운동별 관절 규칙과 임계값은 개발팀이 검증해 PM이 승인한다. 시연용 임시 기준을 쓸 수 있으며, 임시값은 가정, 사유, 영향 화면, 승인 여부를 기록한다.

### 난도 조절

- 충분히 정확하게 수행했을 때만 2회차 난도를 점진적으로 높인다.
- 수행이 부족하면 일괄 상향하지 않고, 근거가 부족하면 분석 불가로 안내한다.
- 2회차 추천에는 근거 기록과 변경 이유를 함께 보여준다.
- 판정 기준, 증가 폭, 안전 상한은 AI 담당이 설계해 PM이 승인한다.

### 독립 진행과 팀 성장

- 참가자의 시작, 휴식, 종료, 퇴장, 연결 오류는 다른 참가자의 운동을 멈추지 않는다.
- 같은 운동 기록으로 팀 경험치를 중복 적립하지 않는다.
- 산식과 레벨 구간은 합의 전까지 임의의 수치로 정하지 않으며, 레벨 상승은 합의된 기준이 있을 때만 표시한다.

### 표현과 개인정보

- 카메라는 사용자가 직접 허용한 경우에만 쓴다. 원본 영상의 처리 위치와 전송 범위는 확정 전까지 사용자에게 단정해 안내하지 않는다.
- 특정 부위 지방 제거나 의료 효과를 약속하지 않는다.
- 목표별로 정해진 루틴이면 'AI' 문구로 개인화 범위를 과장하지 않는다.

## 테스트 결정 (Testing Decisions)

- **유효 횟수 판정**: 새로 촬영한 정상·미흡 동작 사례로 카운트와 미카운트가 의도대로 나오는지, 같은 동작이 중복 카운트되지 않는지 검증한다.
- **인식 실패**: 화면 이탈, 가림, 어두움, 권한 거부, 장치 없음에서 횟수와 자세 결과가 새로 생기지 않는지 검증한다.
- **실제 동작 반영**: 카메라 입력이 없거나 끊기면 캐릭터가 움직임을 임의 생성하지 않는지 검증한다.
- **독립 진행**: 한 참가자의 늦은 시작, 조기 종료, 퇴장, 연결 끊김이 다른 참가자의 진행을 바꾸지 않는지 검증한다.
- **응원 대상**: A가 B를 클릭한 응원이 B에게만 표시되는지 검증한다.
- **난도 정책**: 결과가 좋은 사례, 부족한 사례, 근거 부족 사례에 같은 입력이면 같은 결과가 나오고, 뒤의 둘에서 난도가 오르지 않는지 검증한다.
- **경험치 중복 적립**: 같은 운동 기록을 여러 번 제출해도 한 번만 적립되는지 검증한다.
- **권한 경계**: 다른 참가자의 기록과 추천이 내 결과와 성장 기록에 나오지 않는지 검증한다.
- **빈 성장 기록**: 기록이 없는 사용자에게 예시 수치 없이 빈 상태와 운동 시작 수단만 나오는지 검증한다.
- **공개 파티 개폐 (P1)**: 오픈 전후로 홈 카드 상태와 입장 가능 여부가 설정값과 일치하는지 검증한다.

E2E 대표 여정: 랜딩 → 프로필 설정 → 홈 → 목표 선택 → 루틴 확인 → 운동방 입장 → 실제 운동 → 친구 응원 → 결과 → 2회차 추천 → 2회차 입장 → 성장 기록.

핵심 지표는 P0 통합 테스트 통과 여부다. 발표 환경에서 반복 수행해 통과, 수정 필요, 미구현으로 기록한다. 정확도, 응답속도, FPS 합격 수치는 개발팀이 새 촬영과 다중 PC 테스트 후 제안하고 PM이 승인한다.

## 범위 밖 (Out of Scope)

**나중에 할 것**
- 친구 초대
- 정식 회원가입과 계정 관리
- 긴 온보딩과 사전 운동 테스트
- 4주 단위 프로그램과 개인별 운동 이력 분석(성장 기록 이상의 분석)
- 그룹 챌린지
- 고급 꾸미기, 친구 관리, 상세 통계 (원본 P2)
- 수익화
- 모바일 웹과 네이티브 앱

**안 할 것**
- 측정하지 않은 동작의 카운트와 가짜 운동 기록
- 자동 애니메이션을 실제 움직임으로 표시하는 것
- 2D 배경 이미지만으로 운동방을 대신하는 것
- 모두가 동시에 시작하거나 끝내야 하는 방식
- 부위별 지방 감소나 의료 효과를 약속하는 표현

**이번에 넣지 않는 것**
- 팀 리그, 랭킹, 복잡한 보상
- 음성 통화
- 추천 루틴의 사용자 변경
- 합의되지 않은 기준에 따른 레벨 상승 표시

| 6 | 응원 UI | 운동 진행 화면에 여전히 응원 요소가 없다 | 임의 UI로 확정하기 |
| 7 | 휴식·일시정지 | 휴식 화면의 00:30, 루틴의 '세트 간 휴식 30초', 일시정지 버튼이 미정 규칙과 충돌한다 | 승인 없이 값과 동작 넣기 |
| 8 | 자세 결과 | 결과의 AI 자세 피드백, 성장 기록의 등급(굿·개선 중·노력 필요)과 점수 그래프에 산식이 없다 | 점수·등급을 임의로 계산하기 |
| 9 | 홈·성장 기록 수치 | '이번 주 3회', '연속 5일', '누적 2h 40m'은 계산 규칙이 없는 예시 값이다 | 예시 값을 실제처럼 표시하기 |
| 10 | 선셋 운영 | 와이어프레임의 '매일', 'KST', '닫혀도 운동 중이면 마칠 수 있다'가 명세 규칙에 없다 | 운영 규칙을 임의로 확정하기 |
| 11 | 회차별 목표 | 성장 기록 예시에서 회차마다 목표가 다르다 | 2회차에서 목표 재선택 허용 여부를 임의로 정하기 |

**구현 전에 확인할 가정**

- 인원수: 2~5명, 친구 2~5명, 친구 4~5명, PC 4~5대가 섞여 있다. 본인 포함 여부와 정원 초과 동작을 정한다.
- 팀: 운동방이 곧 팀인지 정한다. ERD는 임시로 한 운동방에 팀 하나를 가정한다.
- 임시 식별: 5일 자체 테스트에서 기기나 세션이 바뀔 때 기록을 어떻게 이을지 정한다.
- 운동 목록: 바닥 자세 운동이 정면 웹캠에서 인식되는지 실제로 확인한다(미확인). 확인되지 않은 운동은 추천에 넣지 않는다.
- 시간 기반 운동: 플랭크의 유효 판정과 기록 방식을 정한다.
- 영상 처리 위치: 기기 내 분석, 동작 정보만 전송, 원본 전송 중 선택한다.
- 일정: 11/12 배포가 촉박하다고 적혀 있고, 5일 자체 테스트가 배포 전인지 후인지는 문서에 없다.

**안내해야 할 오해 소지**

- 초대와 회원가입이 없는 시연 구조는 실제 서비스와 다르다는 점을 발표에서 밝힌다.
- 유주영은 기획용 페르소나이며 실제 사용자 사례가 아니다.
