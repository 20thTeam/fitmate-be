# 수행 기록 제출 형식 (초안)

> S3(이슈 #3) 합의용 초안이다. AI·프론트·백엔드가 확인하면 "초안"을 지운다. 제출은 운동 종료 API(S7, 이슈 #7)로 한다.

## 흐름

1. 카메라 인식과 판정은 **브라우저(AI·프론트)**에서 한다. 동작마다 `유효` / `기준 미달` / `판정 불가` 중 하나로 판정한다.
2. 프론트는 운동 하나가 끝날 때까지 판정 결과를 모은다.
3. 운동 종료 시 운동마다 아래 형식으로 하나씩 묶어 서버에 보낸다.
4. 서버는 측정 상태 규칙을 검사한 뒤 저장한다. 원본 영상과 동작 정보(관절 좌표)는 보내지 않는다.

## API (S7)

| 순서 | 요청 | 하는 일 |
|---|---|---|
| 1 | `POST /api/workouts` `{"routineId": 1}` | 운동 기록 식별값(`workoutId`) 발급, 진행 중. 같은 루틴으로 진행 중인 기록이 있으면 그 기록을 돌려준다(재접속 시 이어 하기) |
| 2 | `POST /api/workouts/{workoutId}/finish` `{"records": [운동 하나의 형식, ...]}` | 수행 기록 확정, 종료. 보내지 않은 운동은 `NOT_MEASURED`(값 모두 `null`)로 저장한다 |

- 두 요청 모두 `X-Participant-Token` 헤더가 필요하다.
- 연결이 끊겨도 운동 기록은 진행 중으로 남는다. 종료 요청을 보내야만 확정된다.
- 종료된 기록에 다시 보내면 `409-1`(이미 종료된 운동 기록입니다)로 거부한다.

## 운동 하나의 형식

```json
{
  "routineExerciseId": 1,
  "measurementStatus": "MEASURED",
  "validCount": 10,
  "belowStandardCount": 2,
  "undeterminedCount": 1,
  "actualSeconds": 95,
  "performedSets": 3,
  "postureResult": { "feedback": ["무릎이 발끝을 넘어요"] }
}
```

| 필드 | 타입 | 필수 | 뜻 |
|---|---|---|---|
| `routineExerciseId` | number | O | 루틴 조회 응답 `exercises[].routineExerciseId` 값 |
| `measurementStatus` | `MEASURED` \| `NOT_MEASURED` | O | 판정 근거가 있었는지 |
| `validCount` | number \| null | 횟수형 측정 시 | 유효로 판정된 동작 수 |
| `belowStandardCount` | number \| null | - | 기준 미달로 판정된 동작 수 (자세 피드백이 뜬 수) |
| `undeterminedCount` | number \| null | - | 판정 불가 동작 수 |
| `actualSeconds` | number \| null | 시간형 측정 시 | 실제 소요 시간(초). 시간형(플랭크)은 유효하게 유지한 시간 |
| `performedSets` | number \| null | - | 수행한 세트 수 |
| `postureResult` | JSON \| null | - | 자세 판정 결과. **형식 미정**이라 AI가 만든 JSON을 그대로 보낸다 (최대 4000자) |

## 규칙

- **측정하지 못한 값은 `0`이 아니라 `null`로 보낸다.** `0`은 "측정했는데 0회"라는 뜻이다.
- `MEASURED`
  - 횟수형(스쿼트 등): `validCount` 필수
  - 시간형(플랭크): `actualSeconds` 필수, `validCount`는 `null`
- `NOT_MEASURED` (권한 거부, 장치 없음, 인식 불가, 연결 끊김 등)
  - `validCount`, `belowStandardCount`, `undeterminedCount`, `postureResult`는 반드시 `null`
  - `actualSeconds`, `performedSets`는 알면 보낸다
- 음수는 받지 않는다.
- 같은 운동 항목을 두 번 보내거나, 그 루틴에 없는 운동 항목을 보낼 수 없다.
- 규칙에 맞지 않으면 `400-4`(수행 기록 값이 올바르지 않습니다)로 응답한다.

## 정해야 할 것

| 항목 | 결정권 | 지금 처리 |
|---|---|---|
| 자세 판정 결과 형식 (점수, 등급, 교정 횟수, 피드백 문구) | PM, AI | JSON 그대로 저장. 정해지면 읽는 쪽만 맞춘다 |
| 시간형 운동의 유효 판정 방식 | AI, PM | `actualSeconds`를 유효 유지 시간으로 받는다 |
| 운동 하나에 일부만 측정된 경우(중간에 카메라 오류) | PM, AI | 판정된 부분이 있으면 `MEASURED`로 보내고, 판정 못 한 동작은 세지 않는다 (제안) |
| 종료하지 않고 나간 운동 기록(강제 종료) | PM | 진행 중으로 남겨 둔다. 결과·경험치에 반영되지 않는다 (임시) |
